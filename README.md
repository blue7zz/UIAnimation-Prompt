# UIAnimation-Prompt

UI 动画提示词。

用于整理和沉淀 UI 动画相关的提示词，方便复用与迭代。

## 开始使用

```sh
git clone https://github.com/blue7zz/UIAnimation-Prompt.git
cd UIAnimation-Prompt
```

当前仓库仅包含基础文档，无需安装依赖，也没有构建或启动命令。

## 提示词记录建议

- **使用场景**：页面、组件及交互目标。
- **触发条件**：点击、悬停、滚动或状态切换等。
- **动画表现**：位移、缩放、透明度、时长及缓动。
- **约束条件**：目标平台、响应式表现及减少动态效果偏好。
- **验收标准**：预期结果、边界状态及参考示例。
